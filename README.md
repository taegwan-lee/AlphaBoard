# AlphaBoard

## 개요
유니티 Sentis를 통해 AI와 플레이 할수 있는 환경의 오셀로 게임 프로젝트
AI는 강화학습을 적용하였으며, 클라이언트 제작은 Unity로 제작하였음.

## 실행 방법
1. 폴더의 AI_Othello.exe 실행

## 주요 기능
- 강화학습 적용된 AI와의 오셀로 전투
- 쉬움, 중간, 어려움 세가지 난이도 적용
- AI는 학습된 onnx모델 기반으로 움직임
- 각 모델별로 코너 및 가장자리, 행동 변화양식 구현

## 기술 스택
- Unity 6000.0.47f1
- C# 스크립트
- PyTorch (모델 학습)
- Unity Sentis (모델 호출 및 전환 적용)
